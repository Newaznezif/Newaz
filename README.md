# Newaz Nezif — Portfolio

Personal portfolio for Newaz Nezif Abagero, a cybersecurity analyst and Information Systems graduate working across security operations, software engineering, data, and applied AI.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
```

## Project structure

- `src/app` — App Router pages, layout, and global styles
- `src/components` — portfolio sections and UI components
- `src/constants` — navigation, profile, experience, skills, projects, and credentials

## Deployment

The production portfolio is hosted at [newaznezif.netlify.app](https://newaznezif.netlify.app).

Update the profile and project data in `src/constants/index.ts`.
